# vaiananna CloudBase 数据设计

这个小程序和别的项目共用同一个文档数据库。隔离方式是集合名前缀：本项目的集合一律以 `vaiananna_` 开头。代码里把前缀收成一个常量，集合名都从它拼出来。索引建在带前缀的集合上。

平台如果允许一个实例里建多个 database，给这个小程序单独一个库，集合名就可以直接用 `user`、`order`。只有被要求写进别人已经在用的同名集合时，才在每条文档上加 `app: "vaiananna"`，并且每条查询都带上这个条件。

## 集合

- `vaiananna_user`
- `vaiananna_address`
- `vaiananna_category`
- `vaiananna_product`
- `vaiananna_sku_spec`
- `vaiananna_sku_spec_value`
- `vaiananna_sku`
- `vaiananna_home_section`
- `vaiananna_home_section_item`
- `vaiananna_cart_item`
- `vaiananna_coupon`
- `vaiananna_user_coupon`
- `vaiananna_red_packet`
- `vaiananna_user_red_packet`
- `vaiananna_order`
- `vaiananna_order_item`
- `vaiananna_comment`
- `vaiananna_comment_image`
- `vaiananna_express`
- `vaiananna_express_trace`

促销如果只是一组商品，再加 `vaiananna_promotion` 和 `vaiananna_promotion_product`。首页、分类叶子上的 `relate_id` 指向 `promotion` 的文档 id。

## 登录与用户

微信登录只代替账号密码。`wx.login` 拿到的 `openid` 只在这个小程序里唯一，用它查出或新建一行 `vaiananna_user`。订单、地址、购物车、优惠券都挂自己的用户文档 id，不要把 `openid` 写进每一张订单。

`vaiananna_user`

| 字段 | 作用 |
|---|---|
| `_id` | 自己的用户主键，地址、购物车、订单都引用它 |
| `openid` | 微信身份，唯一 |
| `unionid` | 同一主体下多个小程序或公众号要打通时才写 |
| `nickname` | 展示名，可空 |
| `avatar_url` | 头像，可空 |

不建用户名和密码。手机号在结算填地址时写入 `vaiananna_address`。

## 文档字段

`link_type`：0 商品、1 促销、2 分类。

### vaiananna_address

`user_id`、`name`、`mobile`、`address`、`street`、`is_default`

### vaiananna_category

分类用一张集合的 `parent_id` 表示树，顶级为 0。现在页面里的三级 `children` 不拆成三张集合。

`parent_id`、`title`、`pic_url`、`sort_order`、`link_type`、`relate_id`

### vaiananna_product

`title`、`description`、`price`、`origin_price`、`promotion`、`detail`、`pic_url`

详情页上的轮播、标签、服务、属性跟着商品走，各自独立成集合，用 `product_id` 关联：

- 轮播：`pic_url`、`sort_order`（可并进商品文档的 `gallery` 数组）
- 标签：`title`
- 服务：`title`、`desc`
- 属性：`name`、`value`

列表卡片只需要 `title`、`description`、`price`、`pic_url`、`link_type`、`relate_id`。

### SKU

`vaiananna_sku_spec`：`product_id`、`name`（颜色、内存）、`spec_key`（`s1`、`s2`）

`vaiananna_sku_spec_value`：`spec_id`、`name`、`pic_url`

`vaiananna_sku`：`product_id`、`price`、`stock_num`、`s1`、`s2`（规格值 id）

每一组规格只能选一个值。各组都选中后，用 `s1` + `s2` 匹配一条 `sku`。购物车存 `sku_id`，同商品不同规格才能分开。

### vaiananna_home_section

`title`、`type`、`sort_order`

板块 `type`：0 轮播、1 频道图标、2 横向商品、3 双图、4 大图带边框、5 大图无边框。

### vaiananna_home_section_item

`section_id`、`title`、`description`、`price`、`pic_url`、`tag`、`link_type`、`relate_id`、`sort_order`

### vaiananna_cart_item

`user_id`、`sku_id`、`count`、`checked`

### vaiananna_coupon / vaiananna_red_packet

优惠券：`title`、`discount`、`description`、`start_time`、`end_time`

红包：同样字段，金额用 `money`。

领取关系在 `vaiananna_user_coupon`、`vaiananna_user_red_packet`：`user_id`、对应券或红包 id、`status`。

### vaiananna_order

`user_id`、`order_sn`、`pay_type`、`total_price`、`express_price`、`actual_price`、`order_status`、`create_time`

地址在下单时写成快照：`address_name`、`address_mobile`、`address`、`street`。

### vaiananna_order_item

`order_id`、`sku_id`、`title`、`spec_desc`、`price`、`count`、`pic_url`

标题、规格文案、单价、图片按下单当时写入。商品以后改价或下架，历史订单仍按这份快照显示。

### vaiananna_comment / vaiananna_comment_image

评价：`user_id`、`order_item_id`、`product_id`、`nickname`、`avatar`、`content`、`rate`、`spec`、`time`

图片：`comment_id`、`pic_url`。图片不多时也可以直接放在评价文档的 `pics` 数组里。

### vaiananna_express / vaiananna_express_trace

物流：`order_id`、`company`、`expno`

轨迹：`express_id`、`text`、`traced_at`。轨迹条数不多时也可以放在物流文档的 `detail` 数组里。

## 状态码

和现有页面判断保持同一套数字。

| 字段 | 取值 |
|---|---|
| 商品 `promotion` | 0 无、1 限时购、2 领券 |
| 券 / 红包 `status` | 0 未使用、1 已使用、2 已失效 |
| 订单 `order_status` | 0 已取消、1 待付款、2 待发货、3 已发货、4 待评价、5 已完成 |
